# 输入系统调用方法

本输入系统采用“栈式层级”架构，通过优先级控制输入的填充、修改和拦截。

## 1. 获取当前帧输入
在任何脚本中，通过单例获取当前帧的最终处理结果：

```csharp
InputFrame frame = InputLayerStack.Instance.CurrentFrame;
```

## 2. 按键状态处理 (ButtonState)
所有动作按键（如 `Confirm`, `Attack`, `Space` 等）均为 `ButtonState` 结构：

- **Down**: 按下的瞬间 (bool?)
- **Hold**: 持续按住状态 (bool?)
- **Up**: 松开的瞬间 (bool?)

### 重要：空值处理
由于输入可能被高优先级层拦截，状态值可能为 `null`。
- `true`: 动作触发。
- `false`: 动作未触发。
- `null`: **输入被阻断**，不应执行任何逻辑。

**推荐写法：**
```csharp
if (frame.Attack.Down == true) 
{
    // 执行攻击逻辑
}
```

## 3. 核心数据字段 (InputFrame)
### A. 主轨道 (Main Track)
通常用于单机游戏或主控制逻辑：
- `Move`: `Vector2?` (WASD / 方向键 / 左摇杆)
- `Confirm`: 确认键 (Enter / Space / 鼠标左键)
- `Cancel`: 取消键 (Esc / 鼠标右键)
- `Attack`: 攻击键 (J / 鼠标左键)
- `Defense`: 防御键 (K / 鼠标右键)
- `CursorPosition`: `Vector2?` 光标屏幕坐标

### B. 多人轨道 (P1 - P4)
对应物理设备的原始映射：
- `P1_Move` 至 `P4_Move`
- `P1_PadA/B/X/Y` 等

## 4. 扩展输入逻辑 (InputLayer)
若需添加自定义的输入处理（如：输入重映射、按键逻辑组合、指令环等），需创建新的输入层：

1. **继承 `InputLayer`**
2. **定义 `Priority`**: 数值越大越后执行（即优先级越高，可以修改/拦截低优先级层的数据）。
   - 硬件源 (`IL_Source`): 100
   - 普通转换层: 建议 0-50
3. **实现 `ProcessInput`**

```csharp
public class IL_YourCustomLayer : InputLayer
{
    public override int Priority => 50;

    public override void ProcessInput(ref InputFrame frame)
    {
        // 读取并修改 frame 里的数据
        if (frame.Move?.magnitude > 0.1f) { /* 处理逻辑 */ }
    }
}
```

## 5. 拦截输入 (Blocking)
在 `InputLayer` 中可以使用内置的 `Block` 方法将特定输入设为 `null`，使其对后续层和最终逻辑不可见：

```csharp
// 拦截整个按键状态
Block(ref frame.Attack); 

// 仅拦截按下事件，保留按住状态
Block(ref frame.Confirm.Down);

// 拦截坐标
Block(ref frame.CursorPosition);
```
