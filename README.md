# 开发准则
## 创建分支
从主分支上新建个人分支，格式以private/acountName/function命名，在个人分支上开发并测试
## 分支合并
向主分支提交更改或者将个人分支与主分支同步使用变基合并（rebase），不要使用merge合并，便于追溯修改历史
如果使用Github Desktop做版本管理，点击Current branch界面，点击最下方Choose a branch to merge into xxxxx...，选择合并来源分支，点击最下方Create a merge commit 右侧的小箭头，在二级菜单最下方找到Rebase并点击以创建一个变基提交
## 注意事项
先在个人分支变基到主分支同步版本后，切换到master主分支，将主分支变基到你的个人分支（搞不清楚的话就只在个人分支上提交，call程序来合分支）
